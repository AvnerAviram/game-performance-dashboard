Squid Game One More Game PAY TABLE REEL WAYS™ pays must occur on adjacent reels, beginning with the far-left reel. All wins on multiple ways are added together. Paytable reflects current bet configuration. The base game contains up to 243 ways to win. WILD SYMBOL The Wild symbol is wild and substitutes for all symbols except for the Blue Flower, Red Flower and Green Flower. The symbol appears on the base game reels 2, 3 and 4. FEATURE SYMBOLS Each feature symbol that lands during the base game will fly into the corresponding colored WINDOW. Any feature symbol may trigger the corresponding WINDOW. More than one WINDOW can be triggered on a single spin. If WINDOW(s) are triggered the corresponding feature will start. The accumulation of feature symbol over time in the RED, GREEN, and BLUE WINDOWS have no effect on triggering the JACKPOT FEATURE or HOLD N' SPIN FEATURE. JACKPOT FEATURE Any RED feature symbol landing in the RED WINDOW may trigger the JACKPOT FEATURE. 15 DOORS will be presented, and JACKPOT ICONS are revealed by clicking on them. DOORS will reveal JACKPOT ICONS or the UPGRADE symbol. Once 3 matching JACKPOT ICONS have been revealed, the corresponding JACKPOT is awarded. If 3 UPGRADE symbols are revealed before a JACKPOT is awarded, the JACKPOTS are upgraded to the next level. If the GRAND JACKPOT is awarded, it will be awarded as the DOUBLE GRAND. The feature ends when one JACKPOT is awarded to the player. HOLD N' SPIN FEATURE 3 spins are awarded initially and the corresponding HOLD N' SPIN FEATURE variation will display 6, 8 or 10 prizes to start. Each time a GREEN PIG symbol lands during the feature spin, it is evaluated and transformed into a GOLD PIG symbol to reveal it's value after all held GOLD PIG symbol and their values are awarded. If multiple GREEN PIG symbols land on the same spin, they are evaluated one at a time. After the first evaluation of the GREEN PIG symbol the previous evaluated GREEN PIG symbol is also awarded as a GOLD PIG symbol. Values displayed are a cash prize and range in value from 0.72 - 180.00 based on the current bet stake. Spins reset back to 3 when 1 or more GREEN PIG symbols land on a spin. If all positions are held, the last evaluated GREEN PIG symbol reveals GRAND JACKPOT and is awarded. If any of the three HOLD N' SPIN FEATURE variations are triggered on the same base game spin along with the JACKPOT FEATURE, then the MINI or MINOR JACKPOTS may also be revealed as a prize. An alternate set of reels is used during the HOLD N' SPIN FEATURE. Ways Pays are not evaluated during the HOLD N' SPIN FEATURE. The Distribution of prizes changes with bet option. The HOLD N' SPIN FEATURE ends when there are no spins remaining or when all positions on the reel array are filled. DDAKJI BONUS During the base game, before pays are evaluated, SUITCASE, landing on an active reel position, will award DDAKJI BONUS. You will be shown a cash prize on top of the RED PAPER. The win from this bonus is 38.88 based on the current bet stake. After the prize is awarded, the game will continue as normal. BUY PASS™ BUY PASS™ allows direct access to the HOLD N' SPIN FEATURE, and does not include the JACKPOT FEATURE and DDAKJI BONUS. The cost of BUY PASS™ 3x5 Grid is equal to 54.00 based on the current bet. The cost of BUY PASS™ 4x5 Grid is equal to 90.00 based on the current bet. The cost of BUY PASS™ 5x5 Grid is equal to 162.00 based on the current bet. The cost of BUY PASS™ Mystery Option is equal to 108.00 based on the current bet. BUY PASS™ Mystery Option will randomly award the 3x5, 4x5, or 5x5 HOLD N' SPIN FEATURE. BUY PASS™ can only be activated in the base game. BUY PASS™ cannot be activated during Autoplay. TURBO MODE Activate Turbo Mode button to speed up each spin, the availability of the off button may be restricted by gameplay conditions until the wagered game is completed. If supported, during the Feature or Bonus game play, Turbo Mode button will automatically be deactivated. Activating Turbo Mode does not influence the results of the play. GAME RULES Only highest win paid per winning combination. Winning combinations may contain only one symbol from each adjacent reel, beginning with the leftmost reel. Like symbols, or their substitute, on a single reel are not part of the same winning combination, but may create separate winning combinations. In accordance with the fair gaming practices, the outcome of each and every game is completely independent. The chances of getting a particular outcome is always the same at the start of every game. The distribution of prizes changes with bet option. Malfunction voids all pays and plays. A stable Internet connection is required. In the event of a disconnection, please relaunch the game to complete any outstanding transactions. The expected return for this game is 93.97%.
