Flippin Rich Fortunes LuckyTap User Interface '+' / '-' buttons increase or decrease the bet value (total bet per round). Starts a game round at the current bet value. Displays autoplay options. Stops the autoplay session. The number displayed shows remaining autoplay rounds. Bet Definitions Current Bet: The value displayed above. Minimum Bet: The lowest possible bet value. Bet Multiplier: Current bet divided by minimum bet. Autoplay Options Autoplay allows automatic game rounds. Select the number of rounds via the autoplay button. Wins The fountain is split into three tiers: Base tier Multiplier tier Jackpot tier A winning play occurs when the coin is successfully tossed into the target. 3 to 14 credit prizes are awarded on a winning play. Multiplier Feature Activated when the coin lands in the multiplier area. Random multiplier (x2 to x7) is applied to all credit prizes. Progressive Pick Bonus Triggered when the coin lands in the bonus area. Player continues picking until 3 symbols fill the meter. The corresponding progressive jackpot is awarded. Multiplier feature is inactive during this bonus. Progressive Jackpot Five jackpots: Mini, Minor, Major, Mega, Super. Match 3 symbols to win the respective jackpot. Only one jackpot can be won per bonus round. Each bet multiplier has separate jackpots and contributions.
