Pipeline Overview

How we classify 5,124 games — from raw sources to dashboard.

1. Matching

Connect each game name to its data sources (screenshot + rules page).

Game List
5,124 game names from master
→
Smart Match
Normalize names, strip punctuation, fuzzy match
→
Screenshot URL
SlotCatalog page identified
Rules Match
Exact title match only. Zero false positives.
→
Rules HTML
~8,800 paytable pages linked

2. Screenshot Acquisition + Pre-Screen

Download screenshots, filter out non-gameplay images.

Download
Playwright grabs highest-res image from SlotCatalog
→
Size Gate
≥60KB pass, <60KB reject (free, catches 50%)
→
Claude Vision
512px · "Is this gameplay?" · $0.0002/img
→
Pass / Reject
Gameplay → art pipeline. Splash → rejected.
↓ training loop
Human: Spot-Check
Review sample results. Mark correct / incorrect.
→
Human: Update Rules
Edit classification prompt based on errors found
→
Claude: Regression
Re-run on all GT images (62). Accuracy improved?
→
Better? ✓ Keep / ✗ Revert
If worse → revert rules, try again. 5 iterations done.

3. Art Classification

Classify visual style — theme, colors, characters, elements — using Claude Vision on two images.

Preprocess
Downscale ≤1568px, JPEG q85, create masked copy
→
Claude Vision
Full img → theme, colors, chars. Masked img → elements.
→
Post-Process
Normalize, remove reel symbols, apply corrections
→
Art Profile
Theme, colors, characters, elements, narrative
↓ training loop
Human: Spot-Check
Review results per dimension. Mark OK or Fix + notes.
→
Human: Update Rules
Add vocabulary, tighten wording, fix hallucination patterns
→
Claude: Regression
Re-classify all 20 GT games with new rules. Improved?
→
Better? ✓ Keep / ✗ Revert
If worse → revert rules, try again. 8+ iterations done.

4. Feature Extraction

Extract game mechanics (features, RTP, volatility) from HTML rules pages using Claude Text.

Clean HTML
Strip nav/scripts, preserve headers and tables
→
Claude Text
Reads rules page, maps to 30 canonical features
→
Normalize
Deduplicate, enforce vocabulary, confidence scores
→
Game Profile
Features, RTP, volatility, symbols, description
↓ training loop
Human: Spot-Check
Review extracted features vs actual rules page
→
Human: Update Rules
Adjust vocabulary, fix missed/incorrect features
→
Claude: Regression
Re-extract all 228 GT games. F1 improved?
→
Better? ✓ Keep / ✗ Revert
Hard gate: blocks if F1 < 95%. Currently 97%.
